# Forma

Мобильное приложение для тех, кто тренируется: спортпит, рационы питания по подписке и AI-консультант, который подбирает набор под цель и бюджет. Рынок — Ташкент, цены в сумах.

**Статус: тестовая версия.** Товары, цены, рационы и промокоды — тестовые данные. Оплаты нет, AI работает локально по правилам, без интернета.

## Что внутри

| Экран | Что делает |
| --- | --- |
| Главная | норма калорий и белка (если заполнена анкета), баннер AI, рационы, популярные товары |
| Спортпит | каталог: поиск, фильтры по категории и цели, карточка товара |
| Рационы | 3 рациона (Масса, Сушка, Поддержание), пример дня, подписка на 7/14/30 дней со скидкой |
| AI-консультант | чат: задаёт вопросы, считает норму, собирает набор из каталога, кнопка «Добавить набор в корзину» |
| Корзина | товары и рацион, код тренера (тест: `TRENER10`), итог, тестовое оформление |
| Анкета → Мой план | рост, вес, цель, зал, бюджет → норма + подбор спортпита |

Защитные правила: до 18 лет и при ограничениях по здоровью добавки не подбираются; на рационе протеин не навязывается; подбор не выходит за бюджет.

## Запуск на iPhone

Нужны Node.js 20+ и приложение **Expo Go** на iPhone (App Store).

```bash
npm install
npx expo start
```

Отсканируй QR-код камерой iPhone — приложение откроется в Expo Go. Телефон и компьютер должны быть в одной Wi‑Fi сети (или запусти `npx expo start --tunnel`).

На Mac с Xcode можно запустить в симуляторе: нажми `i` в терминале после `npx expo start`.

## Структура

```
src/
  app/                 экраны (Expo Router)
    (tabs)/            вкладки: index, catalog, meals, coach, cart
    product/[id].tsx   карточка товара
    plan/[id].tsx      рацион и подписка
    questionnaire.tsx  анкета
    my-plan.tsx        норма и подбор
  components/          UI-компоненты
  data/                ТЕСТОВЫЕ данные: products.ts, mealPlans.ts
  lib/
    nutrition.ts       формулы (Миффлин — Сан Жеор, белок 1,6–2,2 г/кг) и правила подбора
    consultant.ts      локальный AI-консультант (заменить на запрос к бэкенду)
  store/AppStore.tsx   профиль, корзина, код тренера (в памяти)
scripts/test-logic.js  тесты логики
```
